## دليل التشغيل

---

## 1) محتويات المجلد

```
index.html                  الصفحة الرئيسية
pages/constitution.html     الدستور
pages/justice-members.html  أعضاء الوزارة
pages/commercial.html       الغرفة التجارية
pages/projects.html         المشاريع
pages/updates.html          التحديثات
assets/style.css            التصميم
assets/data.js              المحتوى الافتراضي
assets/app.js               محرك الموقع + نظام التحرير
assets/firebase-config.js   إعدادات الحفظ السحابي
assets/logo.svg             الشعار
```

---

## 2) رفع الموقع على GitHub Pages

1. أنشئ Repository جديد (مثلاً: `corven`).
2. ارفع **كل** الملفات كما هي مع نفس ترتيب المجلدات.
3. من `Settings` ← `Pages` ← اختر Branch: `main` والمجلد `/ (root)`.
4. رابط موقعك يصير: `https://اسم-حسابك.github.io/corven/`

---

## 3) التعديل من داخل الموقع

### الدخول
- انزل لأسفل أي صفحة واضغط أيقونة القفل 🔒 في الفوتر.
- أو اضغط **Ctrl + Alt + A** من أي مكان.
- كلمة السر الافتراضية: **`corven2026`**

> غيّرها فوراً من: القفل ← دخول ← ⚙ الإعدادات ← تغيير كلمة السر.

### داخل وضع التحرير
| الأداة | الوظيفة |
|---|---|
| اضغط على أي نص | تعدّله مباشرة |
| **＋ إضافة** | يضيف عضو / مادة / مشروع / تحديث / بند |
| **▲ ▼** | ترتيب العناصر |
| **✕** | حذف العنصر |
| **💾 حفظ** (أو Ctrl+S) | يحفظ التعديلات |
| **⚙ الإعدادات** | تصدير / استيراد / استعادة الأصل / كلمة السر |
| **✕ خروج** | إنهاء وضع التحرير |

كل شي قابل للتعديل: العناوين، النصوص، مواد الدستور، الأعضاء، الرسوم، المشاريع، حتى اسم الوزارة والحقوق في الفوتر.

**مهم:** الزائر العادي ما يشوف أي زر تحرير، وما يقدر يعدّل حرف واحد.

## 4) تفعيل الحفظ للجميع (Firebase)

بدون هذي الخطوة، تعديلاتك تُحفظ في متصفحك أنت فقط. مع تفعيلها، أي تعديل تسويه يظهر لكل الزوار فوراً.

### أ) إنشاء المشروع
1. ادخل <https://console.firebase.google.com> وسجّل دخول بحساب Google.
2. `Add project` ← اسم المشروع: `corven` ← عطّل Google Analytics ← `Create`.

### ب) قاعدة البيانات
3. من القائمة اليمنى: `Build` ← **`Realtime Database`** ← `Create Database`.
4. اختر أقرب منطقة ← اختر **Start in locked mode** ← `Enable`.
5. من تبويب **Rules** الصق هذا بالضبط ثم `Publish`:

```json
{
  "rules": {
    "site": {
      ".read": true,
      ".write": "auth != null"
    }
  }
}
```

> معناها: الكل يقرأ الموقع، وما يكتب إلا حساب مسجّل دخول — يعني أنت وحدك.

### ج) حساب الأدمن (أنت)
6. `Build` ← **`Authentication`** ← `Get started` ← فعّل **Email/Password** ← `Save`.
7. تبويب `Users` ← `Add user` ← اكتب بريدك وكلمة سر قوية ← `Add user`.

> هذا البريد وكلمة السر هي اللي بتدخل فيها لوحة التحكم بعد التفعيل.

### د) بيانات الربط
8. `Project settings` (الترس) ← تحت `Your apps` اضغط أيقونة **`</>`** (Web).
9. سمّه `corven-web` ← `Register app`.
10. بيطلع لك كود فيه `firebaseConfig` — انسخ القيم منه.

### هـ) تعبئة الملف
افتح `assets/firebase-config.js` وعدّله كذا:

```js
window.CORVEN_FIREBASE = {
  enabled: true,

  apiKey:      "AIza...................",
  authDomain:  "corven-xxxx.firebaseapp.com",
  databaseURL: "https://corven-xxxx-default-rtdb.firebaseio.com",
  projectId:   "corven-xxxx",
  appId:       "1:000000000000:web:xxxxxxxxxxxx",

  adminEmail:  "بريدك@gmail.com"
};
```

ارفع الملف على GitHub، وافتح الموقع — بتلاحظ الشارة تحت يسار الشاشة صارت **«متصل بالسحابة»**.

### و) أول حفظ
ادخل بالقفل 🔒 ← بريدك + كلمة سرك ← عدّل أي شي ← **حفظ**.
من هالحين أي زائر يفتح الموقع بيشوف تعديلاتك.

---

## 5) أسئلة سريعة

**نسيت كلمة السر (الوضع المحلي)؟**
افتح `assets/firebase-config.js` وارجع السطر الأخير للقيمة الأصلية، وكلمة السر تصير `corven2026` مرة ثانية.

**أبي أرجع كل شي للأصل؟**
⚙ الإعدادات ← ↺ استعادة الأصل ← ثم حفظ.

**أبي نسخة احتياطية من المحتوى؟**
⚙ الإعدادات ← ⬇ تصدير المحتوى (ينزل ملف JSON). ترجعه بـ ⬆ استيراد محتوى.

**أضفت صفحة جديدة؟**
انسخ أي ملف من `pages/`، غيّر `CORVEN_PAGE` في آخر الملف، وأضف السطر المقابل في مصفوفة `NAV` داخل `assets/app.js`.
